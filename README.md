# 🎓 Intelligent AI Attendance System

## 📌 Project Overview

The **Intelligent AI Attendance System** is an AI-powered application that automates classroom attendance using Face Recognition, Voice Recognition, and QR Code-based subject registration.

It aims to reduce the 10–15 minutes spent on manual attendance in universities by providing a faster and smarter solution.

## 🎯 Key Features

### 👨‍🎓 Student Module
- Student login and registration.
- Face and voice sample registration.
- Subject registration through QR codes.
- View attendance records.

### 👨‍🏫 Teacher Module
- Teacher login.
- Create classes and subjects.
- Generate QR codes for student enrollment.
- Upload classroom photographs.
- Automatically identify students.
- Mark students Present or Absent.
- Manage attendance records.

## 🤖 Technologies Used

- Python

- OpenCV

- Scikit-learn

- Face Recognition
- Voice Recognition
- NumPy and Pandas
- SQLite / MySQL
- QR Code Generation

## 🔄 Project Workflow

1. Students register their face and voice samples.
2. Teachers create classes and subjects.
3. Teachers generate QR codes.
4. Students scan QR codes to enroll in subjects.
5. Teachers upload classroom photographs.
6. The AI model detects and recognizes students.
7. Voice recognition provides additional verification.
8. The system automatically marks attendance as Present or Absent.
9. Attendance records are saved in the database.
